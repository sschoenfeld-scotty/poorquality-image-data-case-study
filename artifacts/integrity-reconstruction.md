# Integrity Reconstruction

One late-stage recovery event became the clearest quantitative example of why the workflow needed evidence governance rather than confidence in previously recorded answers.

An earlier aggregate control set recorded the following results for one source scope.

| Measure | Earlier aggregate control |
| --- | ---: |
| Unique readable people | 220 |
| Zero exact-name matches | 15 |
| Single exact-name matches | 179 |
| Multiple exact-name ambiguities | 26 |

A later direct source-grounded reconstruction found materially different results.

| Measure | Source-grounded reconstruction |
| --- | ---: |
| Unique readable people | 376 |
| Zero exact-name matches | 59 |
| Single exact-name matches | 278 |
| Multiple exact-name ambiguities | 39 |

## What Changed

The source boundary was corrected before the next source type began.

The recovered scope contained

- 33 eligible clean source images
- 525 source appearances
- 376 unique normalized human spellings
- 278 single exact matches
- 39 multiple exact-match ambiguities
- 59 unique zero exact matches
- 59 new person records
- 113 exact-match people enriched
- 155 supported blank fields filled

Existing populated fields were preserved.

## Why The Earlier Result Was Not Forced Back Onto The Source

The historical numbers were treated as evidence that a variance existed, not as a target that the later source review had to reproduce.

The source-grounded reconstruction carried stronger evidence because it was rebuilt directly from the controlled source boundary at the row level.

The earlier result therefore remained part of the audit story without retaining authority over the canonical answer.

> **The historical result became variance evidence, not a target.**

## What This Artifact Demonstrates

This is not presented as a benchmark of model performance.

It demonstrates a governance property of the operating system.

A documented historical answer could be overturned when stronger source evidence appeared.

That distinction matters because a system that protects its prior output from contradictory evidence may be internally consistent and still be wrong.

The integrity standard was therefore not consistency with the earlier answer.

It was consistency with the best available verified source evidence.
